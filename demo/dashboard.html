Auto Model Router — Savings Desk

Opt in to a local usage audit, then apply automation that writes host tier maps. Complements the skill; does not replace Cursor, Claude Code, Codex, or Gemini-style hosts.

Estimates from your routing log, not live Cursor/Claude/OpenAI/Gemini billing. No vendor meter is scraped.

Consent / what is collected. Audit is off until auditOptIn is true in ~/.auto-model-router/config.json. Collected: tier, host, confirmed/overridden, task_kind, optional gate and timestamp. Never: prompts, code, secrets, customer data, vendor credentials, or billing APIs. Relative units: fast=1x, standard=3x, reasoning=8x, max=20x.

AMR = model/effort discipline. Context lean tools (lean.ctx, ponytail, or yours) = send less context — optional peers, not bundled IP. Together they are a usage-discipline stack, not a savings guarantee. See docs/STACK.md.

Enable automation

After you opt in, apply recommendations writes local cursor-tier-map.json (plus Claude/Codex stubs), sets boundaryGatedConfirms=true, and can turn on the weekly digest. AMR still does not flip native Auto.

./scripts/apply.sh --enable-audit --no-open
python3 scripts/audit_usage.py --force
python3 scripts/apply_recommendations.py --enable-weekly-review
