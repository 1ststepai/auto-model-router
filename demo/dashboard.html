Auto Model Router savings estimator

Estimates from your routing log, not live Cursor/Claude billing.

When a log row includes cost_usd (or tokens plus a price table you filled), those measured figures are used. Rows with only a tier fall back to example relative rates: fast=1x, standard=3x, reasoning=8x, max=20x. Percentages from that fallback are estimates from the supplied local routing log, not measured vendor savings. It never accesses credentials, GUI state, or vendor billing APIs.

Use this alongside context tools such as lean.ctx or ponytail: those reduce context sent, while this router addresses model-tier overkill. It can help slow usage burn only when a confirmed lighter tier maps to a cheaper/faster model or lower effort and actually runs. No affiliation is implied, and no savings are guaranteed.
